## 2. Sway หรือ non-sway (§6.6.4.3)

Q = ΣPu·Δo/(Vus·lc) = 24,000 × 3.2 / (900 × 5,000) = **0.0171 ≤ 0.05 → non-sway**

## 3. ความชะลูด (§6.2.5.1)

r = √(Ig/Ag) = h/√12 = 115.47 mm → kl_u/r = 1.0 × 4500 / 115.47 = **38.97**

**ทิศการดัดจากสมดุลแรงเฉือน** (เสาไม่มีแรงกระทำระหว่างช่วง):

- แกน x: |V|·L = 6 × 5.0 = 30 kN·m เท่ากับ |Mt − Mb| = 30 → **โค้งทางเดียว** → M1/M2 = −60/90 = -0.6667
- แกน y: |V|·L = 10 × 5.0 = 50 kN·m เท่ากับ |Mt| + |Mb| = 50 → **โค้งสองทาง** → M1/M2 = +20/30 = 0.6667

- แกน x: เกณฑ์ = min(34 + 12(-0.6667), 40) = **26.00** → 38.97 > 26.00 → **ชะลูด**
- แกน y: เกณฑ์ = min(34 + 12(0.6667), 40) = **40.00** → 38.97 < 40.00 → **ไม่ชะลูด**

## 4. การขยายโมเมนต์แกน x (§6.6.4.4–6.6.4.5)

- Ec = 4700√f′c = 4700√28 = 24,870 MPa
- Ig = bh³/12 = 400 × 400³/12 = 2.1333e+09 mm⁴
- (EI)eff = 0.4EcIg/(1 + βdns) = 0.4 × 24,870 × 2.1333e+09 / 1.6 = 1.3264e+13 N·mm²
- Pc = π²(EI)eff/(kl_u)² = π² × 1.3264e+13 / 4,500² = **6,464.7 kN**
- Cm = 0.6 − 0.4(M1/M2) = 0.6 − 0.4(-0.6667) = 0.8667
- δ = Cm/(1 − Pu/0.75Pc) = 0.8667/(1 − 1,600/(0.75 × 6,464.7)) = **1.2935** ≥ 1.0
- M2,min = Pu(15 + 0.03h) = 1,600 × (15 + 12) = 43.2 kN·m < M2 = 90 → ใช้ M2 = 90 kN·m
- **Mcx = δM2 = 1.2935 × 90 = 116.42 kN·m**
- §6.2.6: Mc/M2 = δ = 1.294 ≤ 1.4 → **ผ่าน**
- แกน y ไม่ชะลูด → ใช้โมเมนต์ลำดับหนึ่ง Muy = 30 kN·m

## 5. แรงอัดสูงสุด (§22.4.2)

Po = 0.85f′c(Ag − Ast) + fyAst = 0.85 × 28 × (160,000 − 2,513.3) + 420 × 2,513.3 = 4,803.8 kN
φPn,max = 0.65 × 0.80 × Po = **2,498.0 kN ≥ Pu = 1,600 kN → ผ่าน**

## 7. แรงอัดร่วมดัดสองแกน (3D interaction)

ตรวจที่ Pu = 1,600 kN สามจุด: ปลายบน (ลำดับหนึ่ง), กลางเสา (Mcx ขยาย + Muy) และกรณีแกน x อย่างเดียว

| จุด | Mux (kN·m) | Muy (kN·m) | มุมโหลด | Mres | φMcap | ratio |
|---|---|---|---|---|---|---|
| ปลายบน (ลำดับหนึ่ง) | 90.0 | 30.0 | 18.4° | 94.9 | 158.0 | 0.600 |
| กลางเสา (Mcx ขยาย + Muy) | 116.4 | 30.0 | 14.5° | 120.2 | 160.3 | 0.750 |

- ตรวจจุดความจุของ solver ด้วย **fiber model อิสระ** (200 × 200 ช่อง) ที่ θ, c เดียวกัน: φPn ต่างกัน 0.005%, φMcap ต่างกัน 0.003%
- ค่าเทียบประกอบ Bresler (§R22.4, ใช้ได้เมื่อ Pu ≥ 0.1f′cAg = 448 kN): Pnx = 3,059, Pny = 4,255, Po = 4,804 kN → Pn = 2,827 kN → Pu/φPn = **0.871** (อัตราส่วนเชิงแรงอัด จึงไม่เท่ากับ ratio เชิงโมเมนต์ แต่ต้องสรุปผ่าน/ไม่ผ่านตรงกัน)

**ข้อสังเกต:** ถ้าไม่คิดการขยายโมเมนต์ ratio ที่กลางเสาจะต่ำกว่าความจริงประมาณ 20% เป็นเหตุผลที่ต้องตรวจความชะลูดก่อนเช็ค interaction

## 8. แรงเฉือน (Table 22.5.5.1, §10.6.2)

- d = h − 60 = 340 mm, Av = 2 × π(10)²/4 = 157.1 mm², Av/s = 0.6283 ≥ Av,min/s = max(0.062√28 × 400/420, 0.35 × 400/420) = 0.3333 → ใช้สมการ (a)
- Nu/(6Ag) = 1,600,000/(6 × 160,000) = 1.667 MPa > 0.05f′c = 1.40 → **ใช้ 1.40 MPa**
- Vc(a) = (0.17√28 + 1.40) × 400 × 340 = 312.7 kN > Vc,max = 0.42√28 × 400 × 340 = 302.3 kN → **Vc = 302.3 kN**
- Vs = Av·fyt·d/s = 157.1 × 420 × 340/250 = 89.7 kN → φVn = 0.75(Vc + Vs) = **294.0 kN ≫ Vu = 6, 10 kN → ผ่าน**
- Vu ≤ 0.5φVc = 113.3 kN → ไม่บังคับปลอกขั้นต่ำ (§10.6.2.1) แต่ปลอกที่ใส่ก็เกินขั้นต่ำ
- แรงเฉือนสองทิศ (§22.5.1.11): อัตราส่วนทั้งสองทิศ < 0.5 → ไม่ต้องตรวจผลรวม
