# ออกแบบ/ตรวจสอบเสา คสล. ตาม ACI 318M-19 (tied, non-sway, biaxial)

**Edition:** ACI 318M-19 (318-19(22) ไม่เปลี่ยนข้อกำหนดทางเทคนิค; errata ต้องตรวจแยก)
**ผู้ใช้:** วิศวกรโครงสร้าง ผลลัพธ์เป็นข้อมูลประกอบรายการคำนวณ วิศวกรผู้รับผิดชอบต้องตรวจและลงนามเอง
**เครื่องมือ:** `scripts/column.py` (solver) — ใช้แทนการคำนวณมือเสมอ และรัน `scripts/test_column.py` เมื่อแก้โค้ด

## 1. Workflow

1. **ตรวจขอบเขต (§2)** — นอกขอบเขตให้แจ้งและหยุด ไม่ใช้สูตรนี้ต่อโดยอัตโนมัติ
2. **รวบรวมอินพุต (§3)** — ถามสิ่งที่ขาด โดยเฉพาะ *นิยาม cover* และ *แกนของโมเมนต์*
3. **แปลงหน่วยเป็น MPa–mm–N** (`kn`, `knm`, `kgf`, `kgfm`, `ksc`)
4. **Sway/non-sway** — `classify_stories` ทุกชั้น ทุกทิศ ทุก combo ที่มีแรงด้านข้าง (§5.1) ถ้าชั้นของเสาเป็น sway → หยุด (ยังไม่รองรับ δs)
5. **ความชะลูดทีละแกน** — `slenderness` (หาเครื่องหมาย M1/M2 ด้วยสมดุลแรงเฉือน §5)
6. **φPn,max** แล้ว **3D interaction** — `capacity_at` ทุก load combination ที่ปลายบน ปลายล่าง และจุดโมเมนต์ขยาย (ถ้าชะลูด)
7. **แรงเฉือนสองทิศ** — `shear_check` (+ `omf_shear` ถ้าเข้า §18.3.3, + `biaxial_shear`)
8. **รายละเอียดเหล็ก** — `longitudinal_checks`, `tie_checks`
9. **รายงาน** ตาม §8 พร้อมสถานะแยกรายการ

## 2. ขอบเขต

| รองรับ | ไม่รองรับ (หยุดและแจ้ง) |
|---|---|
| หน้าตัดสี่เหลี่ยม เหล็กยืนรอบรูป ปลอกเดี่ยว | เสากลม / ปลอกเกลียว, หน้าตัด L/T |
| แรงอัด (หรือแรงดึงเล็กน้อย) ร่วมดัดสองแกน | โครง sway (Q > 0.05), δs (§6.6.4.6) |
| ความชะลูด + ขยายโมเมนต์ non-sway | SMF/IMF (§18.4, §18.7), รอยต่อคาน-เสา (Ch.15) |
| แรงเฉือนสองทิศ, §18.3.3 (OMF ใน SDC B เมื่อผู้ใช้ระบุ) | ผนัง, boundary element, ระยะฝังยึด/ทาบ (Ch.25) |
| λ = 1.0 | คอนกรีตมวลเบา (มีพารามิเตอร์ `lam` แต่ยังไม่ทดสอบ) |

## 3. อินพุต หน่วย และแกน

**แกน:** x ขนานด้าน b, y ขนานด้าน h, จุดกำเนิดที่ศูนย์ถ่วง — `Mux` = โมเมนต์รอบแกน x (ใช้ความลึก h), `Muy` = รอบแกน y (ใช้ความลึก b), P > 0 = อัด
โปรแกรมวิเคราะห์ใช้ชื่อแกนต่างกัน (RCDC: "Mux = along D, major axis") **ต้องยืนยันกับผู้ใช้ว่าโมเมนต์ใดรอบแกนใด** ก่อนคำนวณ

| อินพุต | หมายเหตุ |
|---|---|
| b, h, f′c, fy, fyt, d_agg | fy ในการคำนวณกำลังไม่เกิน 550 MPa (§20.2.2.4) |
| เหล็กยืน: ขนาด, จำนวนต่อด้าน (nx, ny รวมมุม) | `rect_bars(b, h, cover, ds, db, nx, ny, cover_to)` |
| cover + **นิยาม** | `cover_to="tie"` วัดถึงผิวปลอก (ACI), `"long"` วัดถึงเหล็กยืน (RCDC) |
| ปลอก: ขนาด ds, ระยะ s, จำนวนขาแต่ละทิศ | |
| l_u แต่ละแกน, k (non-sway ใช้ 1.0 ได้), ความยาวชิ้นส่วนในการวิเคราะห์ L | |
| ทุก load combination: Pu, Mux/Muy ปลายบน-ล่าง, Vux, Vuy | ไม่ใช่เฉพาะกรณีวิกฤตที่โปรแกรมเลือก |
| β_dns (สัดส่วนแรงอัดค้าง) | ไม่ระบุ → ถามผู้ใช้ (ค่าตัวอย่าง 0.6 เป็นสมมติฐานต้องระบุในรายงาน) |
| ข้อมูลชั้น (ตาราง): ชั้น, ทิศ, combo, ΣPu, Vus, Δo, lc, โมเดลลด stiffness แล้วหรือยัง | ใช้จำแนก sway (§5.1) + ชั้นที่เสาอยู่ |
| ระบบโครงสร้าง / SDC | ใช้ตัดสิน §18.3.3 |

แปลง: 1 kgf = 9.80665 N, 1 ksc = 0.0980665 MPa (280 ksc = 27.46 MPa; SD40 4000 ksc = 392.27 MPa ไม่ใช่ 420)

## 4. กำลังหน้าตัด (3D interaction)

**สมมติฐาน (ข้อกำหนด):** สมดุล + strain compatibility §22.2.1; εcu = 0.003, ไม่คิดแรงดึงคอนกรีต §22.2.2; stress block 0.85f′c ลึก a = β1c §22.2.2.4; fs = Esεs ≤ fy §20.2.2.1; เหล็กอัดใน block หัก 0.85f′c

- `point(sec, θ, c)`: แกนสะเทินตั้งฉากทิศ u = (cos θ, sin θ) — คำนวณ block แบบรูปหลายเหลี่ยมจริง (ไม่ใช้ fiber) ได้ Pn, Mnx, Mny, εt (เหล็กดึงสุด), φ
- **φ (Table 21.2.2, ปลอกเดี่ยว):** εt ≤ εty → 0.65; εt ≥ εty + 0.003 → 0.90; ระหว่างนั้นเชิงเส้น — εty = fy/Es หรือ 0.002 เมื่อใช้ข้อยกเว้น Grade 420 (§21.2.2.1, fy = 420 เท่านั้น ระบุในรายงาน)
- **φPn,max = 0.65 × 0.80 × [0.85f′c(Ag − Ast) + fyAst]** (§22.4.2, Table 22.4.2.1)
- `capacity_at(sec, Pu, Mux, Muy)`: ตัด surface ที่ φPn = Pu แล้ว **หามุมแกนสะเทินที่ทำให้ทิศโมเมนต์ความจุตรงกับทิศโหลด** (มุมแกนสะเทิน ≠ มุมโหลด) → φMcap, ratio = Mres/φMcap ≤ 1
- **ห้ามใช้ Mres เทียบเส้น interaction แกนเดียว** — เสาสี่เหลี่ยมรับโมเมนต์แนวทแยงได้น้อยกว่า (φ ลดลงเพราะเหล็กมุมยืดน้อยลง)
- `surface(sec)` คืนจุดสำหรับพล็อต 3 มิติ; ในรายงานใช้กราฟตัดที่ระดับ Pu (Mx–My) ซึ่งอ่านง่ายกว่า

## 5. ความชะลูดและการขยายโมเมนต์ (non-sway)

### 5.1 จำแนก sway / non-sway (§6.6.4.3, Q ตาม §6.6.4.4.1)

- เกณฑ์ (b): **Q = ΣPu·Δo/(Vus·lc) ≤ 0.05 → non-sway** (เกณฑ์ (a) ΔM ลำดับสอง ≤ 5% ใช้เมื่อมีผล P-Δ)
- อินพุตต่อแถว: ชั้น, ทิศการเซ (x/y), combo ที่มีแรงด้านข้าง, **ΣPu = รวมทุกเสา/ผนังในชั้น** (รวมเสารับแรงแนวดิ่งอย่างเดียว), **Vus = แรงเฉือนของชั้นนั้น** (ไม่ใช่ base shear), **Δo = การเคลื่อนตัวสัมพัทธ์บน−ล่าง จากการวิเคราะห์ลำดับหนึ่ง** (ไม่ใช่โมเดลที่เปิด P-Δ), **lc = ความสูงชั้น c/c** (ไม่ใช่ l_u) — หน่วย Δo กับ lc ต้องเหมือนกัน
- **Δo ต้องมาจากโมเดลที่ลด stiffness** (คาน 0.35Ig, เสา 0.70Ig; §6.6.3.1.1) ถ้าไม่ลด Q ต่ำไป ~2 เท่า
- `classify_stories(rows)` กติกาของสกิล: ใช้ **Q สูงสุดของ (ชั้น, ทิศ)** จากทุก combo ที่ Vus > 0; combo ที่มีแต่แรงแนวดิ่งใช้ผลจำแนกของชั้น/ทิศ (เป็นคุณสมบัติของโครง); ถ้าโมเดลยังไม่ลด stiffness → ถ้า Q/0.35 ≤ 0.05 ยัง non-sway ได้, ถ้า Q ≤ 0.05 < Q/0.35 → **"ต้องยืนยัน"** (ให้รันโมเดลลด stiffness); Q 0.04–0.05 เตือนว่าใกล้เกณฑ์
- **จับคู่แกน:** การดัดรอบแกน x (Mx) เกิดจากการเซทิศ y และกลับกัน (`sway_dir_for_axis`) — RCDC ใช้คำว่า "Along D/B" ต้องยืนยันการจับคู่
- ตัวอย่าง RCDC: Q = 1,083.58 × 0.75 / (49.11 × 1,500) = 0.0110 (lc 1.5 m แปลงเป็น mm)
- r = √(Ig/Ag) (ค่าเริ่มต้น ตรงกับ RCDC) หรือ 0.3h (§6.2.5.2) — ระบุที่ใช้
- **kl_u/r ≤ min(34 + 12 M1/M2, 40)** (§6.2.5.1) โดย **M1/M2 < 0 เมื่อโค้งทางเดียว, > 0 เมื่อโค้งสองทาง**
- **เครื่องหมาย M1/M2 — ห้ามเชื่อเครื่องหมายจากโปรแกรมโดยตรง** (STAAD/RCDC ใช้ member-end convention: ปลายสองข้างเครื่องหมายต่างกัน = โค้งสองทาง) ให้ใช้ `curvature_ratio` ซึ่งตัดสินจากสมดุลแรงเฉือนของเสาที่ไม่มีแรงกระทำระหว่างช่วง:
  |V|·L ≈ |Mt| + |Mb| → โค้งสองทาง; |V|·L ≈ ||Mt| − |Mb|| → โค้งทางเดียว (ตัวอย่าง RCDC: (8.13 + 7.08)/3.0 = 5.07 kN = Vu → สองทาง)
- **M1 = M2 = 0 → ใช้ M1/M2 = −1 (เกณฑ์ 22)** — กติกาของสกิล (มาตรฐานไม่ได้ระบุ) อนุรักษ์นิยมและสอดคล้องกับ Cm = 1.0 ของ §6.6.4.5.4 ต้องระบุในรายงาน (RCDC ใช้ 34 บ้าง 40 บ้าง)
- ถ้าชะลูด: (EI)eff = 0.4EcIg/(1 + βdns) หรือ (0.2EcIg + EsIse)/(1 + βdns) (§6.6.4.4.4), Ec = 4700√f′c;
  Pc = π²(EI)eff/(kl_u)² (§6.6.4.4.2); Cm = 0.6 − 0.4(M1/M2) หรือ 1.0 ถ้ามีแรงกระทำระหว่างช่วง (§6.6.4.5.3);
  δ = Cm/(1 − Pu/0.75Pc) ≥ 1 (§6.6.4.5.2); M2,min = Pu(15 + 0.03h) — ถ้า M2 < M2,min ใช้ M2,min และ Cm = 1.0 (§6.6.4.5.4);
  Mc = δM2; Pu ≥ 0.75Pc → ไม่เสถียร (ไม่ผ่าน); **Mc ≤ 1.4 × โมเมนต์ลำดับหนึ่ง** (§6.2.6)
- โมเมนต์ขยายของสองแกนใช้ตรวจ 3D พร้อมกันที่ Pu เดียวกัน (อนุรักษ์นิยม)

## 6. แรงเฉือน

- `shear_check(sec, "y"|"x", Vu, Nu, s, legs)`: ทิศ y → bw = b, d = ระยะถึงแถวเหล็กไกลสุดในทิศนั้น; Nu > 0 = อัด เกิดพร้อม Vu
- **Vc (Table 22.5.5.1):** Av ≥ Av,min → (a) [0.17λ√f′c + Nu/(6Ag)]bw·d; Av < Av,min → (c) [0.66λsλρw^(1/3)√f′c + Nu/(6Ag)]bw·d, λs = √(2/(1 + d/250)) ≤ 1;
  Nu/(6Ag) ≤ 0.05f′c; Vc ≤ 0.42λ√f′c·bw·d (นี่คือ Vc,max ไม่ใช่ φVc,max); √f′c ≤ 8.3 (§22.5.3.1); ρw ใช้เหล็กครึ่งด้านรับแรงดึง
- **ปลอกขั้นต่ำของเสา: ต้องมีเมื่อ Vu > 0.5φVc (§10.6.2.1)** — ไม่ใช่เกณฑ์ 0.083φλ√f′c·bw·d ของคาน; Av,min/s = max(0.062√f′c·bw/fyt, 0.35bw/fyt) (§10.6.2.2)
- Vs = Av·fyt·d/s (§22.5.8.5.3), φ = 0.75, φVn ≥ Vu; Vu ≤ φ(Vc + 0.66√f′c·bw·d) (§22.5.1.2)
- ระยะปลอกตามแรงเฉือน (เฉพาะเมื่อ Vu > 0.5φVc คือต้องมีเหล็กรับแรงเฉือน): Vs,req ≤ 0.33√f′c·bw·d → s ≤ min(d/2, 600) มิฉะนั้น min(d/4, 300) (§10.7.6.5.2) — ถ้าไม่ต้องมี ระยะปลอกคุมด้วย §25.7.2.1 เท่านั้น
- **แรงเฉือนสองทิศ (§22.5.1.11, ข้อใหม่ 2019):** ถ้าทั้ง vu,x/φvn,x และ vu,y/φvn,y > 0.5 ต้องได้ผลรวม ≤ 1.5 — `biaxial_shear`
- **§18.3.3 (OMF ใน SDC B, l_u ≤ 5c1) ใช้เฉพาะเมื่อผู้ใช้ระบุระบบนี้:** φVn ≥ น้อยกว่าของ (a) (Mnt + Mnb)/l_u โดย **Mn ไม่คูณ φ** ที่ Pn = Pu และ (b) แรงเฉือนจาก combination ที่คูณ E ด้วย Ω0 — `omf_shear` (ไม่มี (b) → ใช้ (a) และหมายเหตุ) ระวัง: RCDC ใช้ φMn ทำให้ Vu1 ต่ำไป ~10% และเมื่อไม่มี load case แผ่นดินไหว min(Vu1, 0) = 0 ซึ่งไม่ถูกต้องถ้าอาคารอยู่ใน SDC B

## 7. รายละเอียดเหล็ก

- เหล็กยืน: 0.01Ag ≤ Ast ≤ 0.08Ag (§10.6.1.1 — ไม่ใช่ §18.7.4 ซึ่งเป็นของ SMF), ≥ 4 เส้น (§10.7.3.1), ช่องว่าง ≥ max(40, 1.5db, 4/3 d_agg) (§25.2.3)
- ปลอก: s ≤ min(16db, 48dbt, ด้านแคบ) (§25.7.2.1); **ขนาด ≥ No.10 (9.5 mm) เมื่อ db ≤ 32 mm, ≥ No.13 (12.7 mm) เมื่อใหญ่กว่าหรือมัดรวม (§25.7.2.2) — RB9 ไม่ผ่าน**; เหล็กมุมและเหล็กเว้นเส้นต้องถูกยึด ช่องว่างถึงเหล็กที่ยึดไม่เกิน 150 mm (§25.7.2.3) — มี crosstie ให้ "ตรวจตามแบบ"
- ระยะหุ้มถึงปลอกตาม Table 20.5.1.3.1 (เสาในอาคารไม่สัมผัสดิน/อากาศ 40 mm) — ถ้า cover วัดถึงเหล็กยืน ต้องหักขนาดปลอกก่อนตรวจ

## 8. รายงาน

เรียง: ข้อมูล → Q → ความชะลูด (แต่ละแกน) → φPn,max → ตาราง 3D check ทุก combination (Pu, Mux, Muy, มุมโหลด, Mres, φMcap, ratio) → แรงเฉือนสองทิศ → detailing แต่ละบรรทัดแสดง สูตร → แทนค่า (MPa–mm) → ผล (kN–m และ/หรือ kgf–m) พร้อมเลขข้อ

| รายการ | สถานะ |
|---|---|
| Sway (Q) | non-sway / **หยุด: sway ไม่รองรับ** |
| ความชะลูดแต่ละแกน | ไม่ชะลูด / ชะลูด (แสดง δ, Mc) / ไม่เสถียร |
| φPn,max ≥ Pu | ผ่าน / ไม่ผ่าน |
| 3D interaction (ratio สูงสุด + combination) | ผ่าน / ไม่ผ่าน |
| แรงเฉือนทิศ x, y, สองทิศ, §18.3.3 | ผ่าน / ไม่ผ่าน / ไม่เข้าเงื่อนไข / **ไม่มีข้อมูล** |
| เหล็กยืน, ปลอก, cover | ผ่าน / ไม่ผ่าน / ตรวจตามแบบ |
| รอยต่อ, ระยะทาบ/ฝังยึด, ผนัง | **ยังไม่ตรวจ** |

ห้ามสรุปว่า "ผ่านครบ" เมื่อมีรายการยังไม่ตรวจ ท้ายรายงานระบุ: edition, εty mode, นิยาม cover, r, β_dns, กติกา M1 = M2 = 0, วิธีตัดสินเครื่องหมาย M1/M2, ขอบเขตที่ไม่รองรับ

## 9. การตรวจกับรายงาน RCDC/STAAD

เมื่อผู้ใช้ส่งรายงาน RCDC มาตรวจ ให้คำนวณซ้ำด้วย solver และระวังจุดที่พบบ่อย:
ป้าย "φVc,max" ที่จริงเป็น Vc,max; Mnt/Mnb ที่จริงเป็น φMn; ตารางอ้าง §18.7.4 กับเสาธรรมดา; นิยาม Mpr เขียน φ = 0.9 (ที่ถูกคือ 1.0 และ 1.25fy); สูตร "34 − 12(M1/M2)" ใช้เครื่องหมายแบบ member-end (ตรวจด้วยแรงเฉือนว่าถูก); กรณีโมเมนต์ปลายเป็นศูนย์ได้เกณฑ์ไม่สม่ำเสมอ; ป้าย "Av/s min-2 0.35 × B" ในทิศ B ควรเป็น D
