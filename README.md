# ACI318-19-Beam

ออกแบบและตรวจสอบคานคอนกรีตเสริมเหล็ก (RC) หน้าตัดสี่เหลี่ยม แบบ **singly / doubly reinforced** ทั้งแรงดัดและแรงเฉือน ตามมาตรฐาน **ACI 318M-19**
(ฉบับ Reapproved 2022 มีเนื้อหาทางเทคนิคเหมือน 318-19)

> ผลลัพธ์ใช้เป็นข้อมูลประกอบแผ่นคำนวณเท่านั้น ต้องมีวิศวกรผู้รับผิดชอบตรวจสอบและลงนามเอง

## Mini app (Python + Streamlit)

แอปมี 2 หน้า เลือกได้จากเมนูด้านซ้าย: **คาน (Beam)** และ **เสา (Column)**

```bash
pip install -r requirements.txt
streamlit run app.py
```

เปิดเบราว์เซอร์ที่ http://localhost:8501

- **แถบข้าง:** วัสดุ (เลือกหน่วย ksc หรือ MPa), หน้าตัด, ปลอก, ตัวเลือกแรงเฉือน, ช่วงคาน (ไม่บังคับ)
- **แท็บ "ออกแบบ":** ใส่ Mu (kgf·m, + ดึงล่าง / − ดึงบน), Vu (kgf) และขนาดเหล็ก → ได้จำนวนเหล็ก (singly หรือ doubly) และระยะปลอก
- **แท็บ "ตรวจสอบ":** ใส่จำนวนเหล็กดึงต่อชั้น เช่น `4,2`, เหล็กอัด และระยะปลอก → ได้ φMn, εt, φVn
- แสดงรูปหน้าตัด ตารางสถานะ (ผ่าน / ไม่ผ่าน / ยังไม่ตรวจ) และรายการคำนวณทีละขั้น ดาวน์โหลดรายงานเป็น `.md` ได้

### หน้าเสา (Column)

ใช้ solver จาก skill [`skills/rc-column-aci318m19`](skills/rc-column-aci318m19/SKILL.md) (เสาสี่เหลี่ยม ปลอกเดี่ยว โครง non-sway)

- **แถบข้าง:** วัสดุ, หน้าตัดและเหล็ก (เลือกได้ว่า cover วัดถึงปลอกหรือถึงเหล็กยืนแบบ RCDC), l<sub>u</sub> / k แต่ละแกน, β<sub>dns</sub>, ตัวเลือก §18.3.3
- **ขั้นที่ 1 ด่านตรวจ sway (บังคับ):** ปุ่มตรวจสอบเสาในขั้นที่ 2 จะกดได้เมื่อชั้นของเสามีข้อมูลครบทั้งทิศ x และ y และเป็น non-sway ทั้งคู่ — **การออกแบบเสา sway ปิดปรับปรุง** · มีตัวเลือก **ข้ามการตรวจ sway** เมื่อวิศวกรยืนยันเองว่าเป็น non-sway (ต้องใส่เหตุผล ซึ่งพิมพ์ลง Calsheet และแสดงสถานะ "ผู้ใช้ยืนยัน") ใช้ได้เมื่อไม่มีข้อมูล Q หรือผล "ต้องยืนยัน" — ข้ามไม่ได้ถ้าข้อมูลแสดงว่า sway
- **ตารางข้อมูลชั้น (จำแนก sway / non-sway):** ชั้น, ทิศ, combo, ΣP<sub>u</sub>, V<sub>us</sub>, Δ<sub>o</sub>, l<sub>c</sub> และช่องติ๊ก "ลด stiffness แล้ว" ทุกชั้นทุกทิศ → แอปคำนวณ Q, ใช้ Q สูงสุดของแต่ละชั้น/ทิศ แล้วนำผลของ**ชั้นที่เสาอยู่**ไปใช้ (ชั้นที่เป็น sway → หยุด เพราะยังไม่รองรับ δ<sub>s</sub>)
- **ข้อมูลแรงแบบ STAAD.Pro (แนะนำ):** วางค่าจาก Member End Forces ตามที่ STAAD แสดง (Fx, Fy, Fz start; My, Mz start/end) แอปแปลงเป็น P / Mx / My / V ให้ (Mz → Mx, Fy → Vuy, My → My, Fz → Vux, มีตัวเลือก beta 90° และกลับเครื่องหมาย P) พร้อมตัวป้องกัน sign convention: combo แนวดิ่งล้วนต้องได้แรงอัด, แรงเฉือนต้องสอดคล้องกับโมเมนต์ (±10%) และเสาไม่จัตุรัสต้องยืนยันว่า h = YD
- **ตารางแรง (ป้อนเอง):** กรอกหรือวางจาก Excel ได้หลาย combination (P<sub>u</sub>, M<sub>x</sub> / M<sub>y</sub> ปลายบน-ล่าง, V<sub>uy</sub>, V<sub>ux</sub>) หน่วย kN–m หรือ kgf–m
- **ผลลัพธ์:**
  - กราฟ **3D interaction surface** หมุนดูได้ พร้อมจุดโหลดทุก combination
  - กราฟตัด M<sub>x</sub>–M<sub>y</sub> ที่ระดับ P<sub>u</sub>
  - ตาราง ratio ทุกจุด (ปลายบน, ปลายล่าง และกลางเสาเมื่อชะลูด)
  - ตารางความชะลูด, แรงเฉือน และสรุปสถานะ
  - **Calsheet A4** ของเสา
- ค่าเริ่มต้นคือตัวอย่างเสาชะลูด S1 ([รายการคำนวณมือ](skills/rc-column-aci318m19/references/example-slender-column.md))

## ขอบเขต

**รองรับ**
- คานหน้าตัดสี่เหลี่ยม ไม่อัดแรง ไม่มีแรงตามแกนหรือแรงบิด
- แรงดัด: singly และ doubly (เหล็กอัดครากหรือไม่ครากก็ได้, เหล็กหลายชั้น)
- แรงเฉือน: ปลอกตั้งฉาก, Vc ตาม Table 22.5.5.1
- โหมด **ออกแบบ** (หาเหล็ก) และ **ตรวจสอบ** (วิเคราะห์หน้าตัดที่กำหนด)

**ยังไม่รองรับ**
- T/L-beam, แรงบิด, แรงตามแกน
- คานต่อเนื่องที่ต้อง redistribute moment
- Deep beam (Ch. 23), ข้อกำหนดแผ่นดินไหว SMF/IMF (Ch. 18)
- ปลอกเฉียง / เหล็กงอรับแรงเฉือน
- คอนกรีตมวลเบา (λ ≠ 1 ส่งผ่านพารามิเตอร์ได้ แต่ยังไม่ได้ทดสอบ)

## หน่วย

ผู้ใช้ป้อนและอ่านผลเป็น kgf–m ส่วนการคำนวณภายในใช้ MPa–mm–N

| รายการ | หน่วยผู้ใช้ | หน่วยภายใน |
|---|---|---|
| แรง | kgf | N (×9.80665) |
| ขนาด, ระยะ | m | mm (×1000) |
| โมเมนต์ | kgf·m | N·mm (×9,806.65) |
| f′c, fy, fyt | ksc (kgf/cm²) | MPa (×0.0980665) |
| พื้นที่เหล็ก | cm² | mm² (×100) |
| ขนาดเหล็ก, ระยะปลอก | mm | mm |

ตัวอย่าง: 280 ksc = 27.46 MPa, 4000 ksc = 392.27 MPa (ไม่ใช่ 420 MPa)

## อินพุตที่ต้องใช้

- ขนาดหน้าตัด b, h
- กำลังวัสดุ f′c, fy, fyt
- ระยะหุ้ม (cover) ตามสภาพแวดล้อม (Table 20.5.1.3.1)
- ขนาดปลอก, ขนาดเหล็กหลัก และเหล็กรับแรงอัด
- Mu (พร้อมเครื่องหมาย: + ดึงด้านล่าง, − ดึงด้านบน) และ Vu
- โหมด: ออกแบบ หรือ ตรวจสอบ

## ขั้นตอนการคำนวณ

1. ตรวจขอบเขต ถ้าเกินขอบเขตให้หยุด
2. แปลงหน่วยเป็น MPa–mm–N
3. ระบุด้านรับแรงอัด/แรงดึงจากเครื่องหมายโมเมนต์
4. **แรงดัด**: ลอง singly ก่อน ถ้าไม่ผ่านจึงใช้ doubly หรือในโหมดตรวจสอบให้หาค่า c จากสมดุลแรง ΣF(c) = 0 (bisection)
5. คำนวณ d, dt, d′ ใหม่จากเหล็กที่เลือกจริง แล้วตรวจ φMn และ strain อีกครั้ง
6. **แรงเฉือน**: Vc, Av,min, ระยะปลอก และตรวจขนาดหน้าตัด
7. **Detailing**: เหล็กขั้นต่ำ, ระยะห่างเหล็ก, crack control
8. รายงานสถานะแยกทีละรายการ

## หลักการสำคัญ

### แรงดัด
- Stress block 0.85f′c, a = β1c (β1 = 0.85 เมื่อ f′c ≤ 28 MPa ลดลง 0.05 ต่อ 7 MPa ต่ำสุด 0.65), εcu = 0.003, fs = Es·εs ≤ fy, Es = 200,000 MPa
- **Tension-controlled (§9.3.3.1):** εt ≥ εty + 0.003 (ไม่ใช้เกณฑ์ 0.004 ของฉบับเก่า)
  - fy = 420 MPa → εty = 0.0021, cmax = 0.37037·dt
  - ทางเลือกตาม §21.2.2.1 สำหรับ Grade 420: εty = 0.002, cmax = 0.375·dt (ต้องระบุในรายงาน และห้ามใช้ปนกับวิธีแรก)
- φ ตาม Table 21.2.2: 0.90 / ช่วง transition / 0.65
- ถ้า strain ไม่ผ่าน ให้รายงานว่า **"Strain limit: ไม่ผ่าน"** แยกจากกำลังดัด แม้ φMn ที่ลดค่าแล้วจะยังพอ
- Doubly: ห้ามสมมติว่าเหล็กอัดครากเสมอ
  - d′ ≤ a → Cs = A′s(f′s − 0.85f′c)
  - a < d′ < c → Cs = A′s·f′s (ไม่หักคอนกรีตที่ถูกแทนที่)
  - d′ > c → เหล็กชั้นนั้นรับแรงดึง
- แยก **dt** (ใช้หา εt และ cmax) ออกจาก **d** (จุดศูนย์ถ่วงเหล็กดึง) เมื่อมีเหล็กหลายชั้น

### แรงเฉือน
- Vc ตาม Table 22.5.5.1 เลือกสมการจากปลอกที่จัดให้จริง
  - Av/s ≥ Av,min/s: (a) 0.17λ√f′c·bw·d หรือ (b) 0.66λρw^(1/3)√f′c·bw·d
  - Av/s < Av,min/s: (c) 0.66λsλρw^(1/3)√f′c·bw·d, λs = √(2/(1 + d/250)) ≤ 1
  - √f′c ≤ 8.3 MPa และ Vc ≤ 0.42λ√f′c·bw·d
- ต้องใส่ปลอกขั้นต่ำเมื่อ Vu > 0.083φλ√f′c·bw·d (§9.6.3.1)
- Av,min/s = max[0.062√f′c·bw/fyt, 0.35bw/fyt] (Table 9.6.3.4)
- ขนาดหน้าตัด (§22.5.1.2): Vu ≤ φ(Vc + 0.66√f′c·bw·d)
- Vs = Av·fyt·d/s, φ = 0.75

### Detailing
- As,min (§9.6.1.2) = max[0.25√f′c/fy, 1.4/fy]·bw·d (fy ไม่เกิน 550 MPa)
- ระยะห่างเหล็ก §25.2.1 และ §25.2.2 (หลายชั้น)
- Crack control Table 24.3.2 โดยใช้ fs = 2fy/3
- ระยะปลอก Table 9.7.6.2.2
- ความลึกขั้นต่ำ Table 9.3.1.1

### Load combination
ถ้ามีเฉพาะ D และ L ใช้ U = 1.4D และ 1.2D + 1.6L ได้ ถ้ามีโหลดอื่นต้องใช้ชุดที่เกี่ยวข้องตาม Table 5.3.1

## รูปแบบรายงาน

แต่ละขั้นแสดง สูตร → แทนค่า (MPa–mm) → ผล (kgf–m, cm²) พร้อมเลขข้อ และสรุปสถานะ:

| รายการ | สถานะ |
|---|---|
| กำลังดัด (φMn ≥ Mu) | ผ่าน / ไม่ผ่าน |
| Strain limit (εt ≥ εty + 0.003) | ผ่าน / ไม่ผ่าน |
| กำลังเฉือน + §22.5.1.2 | ผ่าน / ไม่ผ่าน |
| เหล็กขั้นต่ำและ detailing | ผ่าน / ไม่ผ่าน / ยังไม่ตรวจ |
| Deflection | ยังไม่ตรวจ (เว้นแต่ตรวจจริง) |
| Development / anchorage (Ch. 25) | ยังไม่ตรวจ |

รายการที่ไม่ได้ตรวจต้องเขียนว่า "ยังไม่ตรวจ" และห้ามสรุปว่าคานผ่านครบทุกข้อ
